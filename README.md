# Retrace

Веб-сервис для разбора GPS-треков с часов (`GPX`, `FIT`, `TCX`): анимированное сравнение нескольких участников на карте.

## Два типа событий

Тип выбирается при создании события (кнопка «Новое событие») и меняется в его настройках (карандаш).

- **🧭 Ориентирование** — свой растр поверх подложки:
  - скан или фото карты спортивного ориентирования либо скриншот Google Maps (`PNG`, `JPG`, `WebP`, `GIF`);
  - подгонка мышкой и ползунками масштаба, поворота и растяжения вокруг якоря «⚓ СТАРТ»;
  - **масштаб и север**: точный размер по масштабу печати (1:4000…1:15000) и DPI скана (DPI читается из файла скана, если сканер его записал) или по масштабной линейке; карта ориентирования поворачивается на магнитный север (склонение по модели WMM2025 для места и даты забега), скриншот Google — строго на истинный север;
  - **КП дистанции**: старт, КП и финиш отмечаются кликами по карте и двигаются вместе с ней; по трекам находятся отметки на КП (по порядку, с учётом петель) → **сплиты** по перегонам с местами; клик по перегону запускает всех с его начала;
  - **доводка трека до КП** (как корректировка маршрута в Livelox): трек сдвигается так, чтобы проходить через отметки, снос GPS поперёк хода убирается;
  - пуск всех треков с выбранной точки, анализ перегона A → B и выравнивание скорости как в Livelox («По силам», «Равная»).
- **🏃 Забег / хайк** — без своей карты, на подложке OpenTopoMap (горизонтали и тропы) с переключением на OSM и спутник.

## Общее для обоих типов

- Создание событий без регистрации и шаринг по ссылке (`/?event=<slug>`).
- Чистка GPS: первые неточные точки после включения часов и одиночные скачки «туда и обратно» отбрасываются; сглаженный темп; режимы времени «С 1 места (00:00)» и «Реальное время GPS», сдвиг участника ±5 с.
- Хвосты (30 с … весь путь), окраска по темпу, скорость воспроизведения 1×…60×, живая таблица (темп, скорость, дистанция, отставание, пульс, высота) и график скорости.

## Быстрый старт

```bash
npm install
npm run dev:server   # API (Fastify): http://localhost:3001
npm run dev:web      # фронтенд (Vite): http://localhost:5173
```

Данные событий и загруженные карты хранятся в `data/` (в Docker — том `/opt/retrace/data`).
