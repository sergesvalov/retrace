# Retrace

Веб-сервис для загрузки растровых карт (скриншоты Google Maps / OpenStreetMap, карты спортивного ориентирования), их геопривязки по контрольным точкам (GCP) и анимированного сравнения GPS-треков нескольких участников с часов Garmin (`GPX`, `FIT`, `TCX`).

## Возможности MVP

- **Создание событий без регистрации** и мгновенный шаринг по ссылке (`/?event=<slug>`).
- **Split-view геопривязка карты (`GeorefWorkspace`)**:
  - Загрузка любого изображения (`PNG`, `JPG`, `WebP`, `SVG`).
  - Привязка кликами «точка на картинке ↔ точка на подложке OpenStreetMap» (перетаскиваемые маркеры).
  - Две математические модели в проекции Web Mercator (`EPSG:3857`): **Similarity** (2+ точек: сдвиг, масштаб, поворот) и **Affine МНК** (3+ точек: 6 параметров с расчётом среднеквадратичной невязки `RMS` в метрах).
- **Мульти-трековый плеер и аналитика (`ReplayWorkspace`)**:
  - Загрузка треков Garmin в форматах `.fit`, `.gpx`, `.tcx` с фильтрацией выбросов и расчётом сглаженного темпа.
  - Синхронизация времени: режим **«Масс-старт (от 00:00)»** и **«Реальное время GPS»**, плюс ручной сдвиг старта (`±5с`) для каждого участника.
  - Анимированные маркеры и хвосты (`30 сек`, `2 мин`, `5 мин`, `весь путь`), режим окраски треков по скорости (**Темп-хитмап**), скорости воспроизведения `1×..60×`, живая таблица лидеров (темп `/км`, скорость `км/ч`, дистанция, отставание в метрах, пульс, высота) и интерактивный график скорости.
- **Встроенное демо-событие**: карта спортивного ориентирования (Битцевский лес, 1:7500) + 3 участника с разными вариантами прохождения дистанции.

## Быстрый старт

```bash
npm install
npm run dev
```

- Бэкенд API (Fastify): `http://localhost:3001`
